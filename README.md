# New BSOD has arrived. 
This aims to replicate the new BSOD introduced Windows 11, version 24H2 and later releases.


1. Download the ZIP from the Releases page
 2. Navigate to your Downloads folder
`cd C:\Users\USERNAME\Downloads`

 3. Enter the extracted project folder (the name may vary depending on GitHub archive)
`cd BugCheck-Mockup-PowerShell-24H2-25H2-26H1-1.0.0`

 4. Allow script execution for this session (required for unsigned scripts)
`Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass`

 5. Run the script
`.\BugCheck-Mockup.ps1`

# Press Escape at any time to close the simulation.
